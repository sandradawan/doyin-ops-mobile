# DoyinOps — SME mobile tool

Simple, valuable phone app for Nigerian / African small businesses:

- **Cash tracker** — log money in / out, see 7-day net
- **WhatsApp scripts** — greeting, price ladder, follow-up, deposit, review (copy → paste)
- **Leads pipeline** — New → Chat → Proposal → Paid (open WhatsApp in one tap)
- **Tasks** — daily Most Important Tasks

All data stays on the device (AsyncStorage). No account required.

## Test on your phone (Expo Go)

```bash
git clone https://github.com/sandradawan/doyin-ops-mobile.git
cd doyin-ops-mobile
npm install
npx expo start
```

Scan the QR code with **Expo Go** (Play Store / App Store).
